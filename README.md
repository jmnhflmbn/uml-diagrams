- 🔍 توضيح عناصر المخططات ورموزها.
- 🧩 شرح العلاقات بين مكونات الأنظمة.

## 🗂️ المخططات المتوفرة

<div dir="rtl" align="right">

| المخطط | الاسم بالعربية | الاستخدام |
|---|---|---|
| Use Case Diagram | مخطط حالات الاستخدام | توضيح تفاعل المستخدمين مع النظام |
| Activity Diagram | مخطط الأنشطة | توضيح تسلسل الأنشطة وتدفق العمل داخل النظام |
| Class Diagram | مخطط الفئات | عرض الفئات وخصائصها وعملياتها وعلاقاتها |
| Object Diagram | مخطط الكائنات | عرض أمثلة للكائنات وعلاقاتها في وقت محدد |
| Sequence Diagram | مخطط التسلسل | توضيح ترتيب الرسائل بين مكونات النظام |
| Communication Diagram | مخطط التواصل | توضيح التفاعل والروابط بين الكائنات |
| State Machine Diagram | مخطط آلة الحالات | توضيح حالات الكائن وانتقالاته |
| Component Diagram | مخطط المكونات | توضيح مكونات النظام واعتمادياتها |

</div>

## 🚀 طريقة استخدام المشروع

<div dir="rtl" align="right">

1. افتح مستودع المشروع على GitHub.
2. نزّل المشروع إلى جهازك أو استنسخه باستخدام Git.
3. افتح مجلد المشروع.
4. افتح ملف `uml.html` باستخدام متصفح الويب.
5. تصفّح قائمة المخططات الموجودة في الصفحة الرئيسية.
6. استخدم شريط البحث للعثور على المخططات حسب الاسم أو التصنيف.
7. اختر المخطط الذي تريد دراسته.
8. اقرأ الشرح وتعرّف على العناصر والعلاقات، ثم اطّلع على المثال التوضيحي.</div>
